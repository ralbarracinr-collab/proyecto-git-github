# Mi Proyecto Web

Proyecto web desarrollado para aprender a utilizar Git y GitHub mediante el control de versiones.

## Descripción

Este proyecto consiste en una página web básica desarrollada con HTML.

El objetivo es practicar el uso de repositorios, ramas, commits y Pull Requests utilizando Git y GitHub.

## Mejoras implementadas

- Menú de navegación con enlaces internos.
- Formulario de contacto con campos para nombre, correo electrónico y mensaje.

## Estructura del proyecto

- `index.html`: página principal del proyecto.
- `.gitignore`: archivo que excluye la carpeta `.vscode`.
- `README.md`: documentación del proyecto.

## Tecnologías utilizadas

- HTML5
- Git
- GitHub
